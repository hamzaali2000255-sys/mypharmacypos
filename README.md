# MyPharmacyPOS

Pharmacy-focused POS and inventory management system built for XAMPP/Windows, with support for full packs, strips, and loose-tablet sales.

## Planned modules

- Pharmacy POS checkout
- Loose tablet / unit selling with automatic unit conversion
- Batch and expiry tracking
- Medicine inventory
- Purchases and suppliers
- Sales, returns and payments
- Profit and sales reporting
- Low-stock and expiry alerts
- User roles and permissions
- Audit-friendly stock movements

## Development

This repository is currently being initialized as a pharmacy-focused POS. The design is intended to be compatible with a local XAMPP deployment and to follow open-source POS principles.
